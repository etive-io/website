In preparation for the upcoming IR1 observing run of the LIGO, Virgo, and Kagra gravitational-wave detectors, we're pleased to announce the release of asimov 0.8.0.
This release brings a lot of new features, and we've been working steadily to improve both the efficiency of the code and the things it can do for the last couple of years since the v0.5 series of releases which were used in the O4 observing run.

While I'm going to concentrate mostly on things which will be helpful for gravitational-wave analyses in this post, we've also done a lot of work to make asimov a tool which is useful for a wider range of analysis problems, including most recently putting together a pulsar timing array analysis pipeline, which I'll write a post about soon.
