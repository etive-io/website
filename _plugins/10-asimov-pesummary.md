# asimov-pesummary

Integration between Asimov and PESummary for post-processing and visualization of parameter estimation results.

## Features

- **Plugin architecture** integrating with Asimov via entry points
- **Result summarization** with automatic generation of summary pages from PE results
- **Visualization** with automated plot generation and result presentation
- **Multi-analysis support**, combining results from multiple analyses

## Installation

```bash
pip install asimov-pesummary
```

## Purpose

PESummary post-processes and visualizes the output of parameter estimation pipelines, producing the summary pages and comparison plots used to review and publish analysis results.
